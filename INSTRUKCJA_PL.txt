MK Brows & Lashes — aktualizacja z prywatnym rejestrem pracy w domu

WDROŻENIE
1. Zrób kopię zapasową w obecnej aplikacji.
2. Rozpakuj ZIP.
3. W repozytorium GitHub wybierz Add file → Upload files.
4. Wgraj zawartość tego folderu (index.html, service-worker.js, manifest.webmanifest, mk-logo.png i folder icons) do katalogu głównego.
5. Kliknij Commit changes. Nie zmieniaj adresu repozytorium.

UŻYWANIE UKRYTEJ SEKCJI
Kliknij logo MK pięć razy w krótkim odstępie. Przy pierwszym wejściu ustawisz hasło, potem będzie ono wymagane. Sekcja ma osobne wpisy, podsumowania i eksport CSV.

WAŻNE O PRYWATNOŚCI
Hasło i wpisy są zapisane lokalnie w przeglądarce. To ukryta sekcja, nie profesjonalne zabezpieczenie: osoba mająca dostęp do urządzenia lub plików aplikacji może je obejść. Dane domowe są osobne od salonowych. Kopia JSON obejmuje również wpisy domowe po tej aktualizacji.
